# odin-landing-page

## Description

The project is about creating a landing page using both HTML and CSS. The page contains different sections with texts and images including a header and a footer. Although the layout is identical, most of the information on the page is modified to fit my own preferences as instructed in the project assignment.

## Skills

The skills I needed to demonstrate in this project are -

1. Work with both HTML and CSS files simultaneously.
2. Create different required classes in HTML.
3. Inspect other web pages for ideas.
4. Use flexbox to align and position items in CSS.
5. Build a webpage from scratch with necessary design elements.
